# AI trial 2026-10-24, second run: Claude Haiku 5.5, 30 requests

Same 30 requests, model and setup as [the first run](2026-10-24-haiku.md), after its first four
recommendations were built:

1. **Too big for the bed** is a problem row (so "Copy for AI" says it); the prompt says all parts,
   gaps included, must fit.
2. **Convert to sketches** puts code blocks in a row with the same op into one block.
3. **Overhangs steeper than 45°** are a problem row (`src/overhangs.ts`, measured like the judge);
   the prompt asks for none.
4. **Library hints list the module's parameters** (BOSL2/MCAD, from the bundled source) for a failed
   check inside a library module and for an argument the module doesn't have.

Cost $0.37 in all (#12 was asked again: the chat CLI gave no answer the first time).

## What the new checks did

- **Overhangs** caught #2 (a 59° screw-cap underside) and #22 (hook shafts at 50°); one round fixed
  both, with the reason stated ("I changed each hook to a convex hull of the vertical root and the
  tip ball … about 27° from vertical"). The app and the judge agree on the number and places of
  overhangs in all 35 rendered rounds, and on 14 other real models; the check takes under 15 ms.
- **Library parameters**: #14 passed `nutthick` and #17 `nutwall` to `threaded_nut()`. The hint
  named the wrong argument and listed the parameters; both answers used `nutwidth` in the next round,
  and the nut was kept (in the first run #17 gave up the nut).
- **Bed size**: nothing was too big this time (the first run's #24 was 212 mm); the prompt line and
  the row are covered by tests.
- **Convert**: the honeycomb (#11) and the lamp shade (#24) now have no or one code block; the
  remaining blocks are threads, a twisted vase and BOSL2 shapes, which rightly stay code.
- The flat-ceiling check caught #7 (34 mm) and #12 (60 mm) as before, each fixed in one round.
