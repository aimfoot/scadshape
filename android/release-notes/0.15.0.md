Three ways of working, a Render button for your own code, and a warm orange look.

- **Draw, Code and Paste:** a switch at the top replaces the source drop-down. **Draw** is sketches and features, as before. **Code** is a plain OpenSCAD editor for writing the code yourself: your code or a code example, the 3D view and the problems in the code, with no AI aids. **Paste** is for code from an AI chat: copy the prompt, paste the answer, copy the problems back.
- **Your code and pasted code are kept apart:** pasting an AI answer never replaces the code you wrote yourself.
- **Render when you want:** in Code the model no longer re-renders while you type. Tap **Render** in the corner of the code (it turns orange when the code has changed), or press Ctrl+Enter. Pasted code still renders by itself.
- **Start card:** **Copy prompt** takes you on to Paste, and a new **Write code** button opens Code.
- **Warm orange:** the model is orange instead of grey, and the app's accent colour follows it. Measure marks and selected points on the model are blue so they stand out.
- The button that shows the model's generated code in Draw is now a `</>` icon.
