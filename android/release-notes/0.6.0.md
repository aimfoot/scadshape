When pasted code has problems, the app now says what is wrong in plain words, and can hand it straight back to the AI that wrote it.

- **Problems under the code:** one row per problem, with its line and an explanation, instead of a raw log where AI-written code can repeat the same warning thousands of times. Tap a problem to jump to its line. The full log is still there behind **Full log**.
- **Typical AI mistakes are recognised:** functions OpenSCAD doesn't have (such as `radians()`), a forgotten `include <BOSL2/…>` (and which BOSL2 file is needed), `+=`, Python-style loops, `return`, typos ("Did you mean width?"), the MCAD library, mixed 2D and 3D, and errors inside a library, shown on the line that called it.
- **Copy for AI:** puts the problems and their lines of code on the clipboard, ready to paste back into the chat the code came from.
- **The status bar says "· 1 problem"** also when the model rendered but parts are missing, so a half-finished model no longer looks fine.
- **Convert to sketches:** a dimension that depends on a product of variables (such as `m * z`) no longer gets a built expression that is only right at the start values. An expression written in the code is still used as it is.
