One model, two ways to work on it: Draw and Code. Coloured code, a tidier top bar, and text on undersides that reads the right way round.

- **Draw and Code, one model:** the switch at the top is now **Draw** and **Code**, two views of the same model. Code shows the model's OpenSCAD code and you can change it right there. Changing a drawn model's code makes it a model that is code (Undo in Draw brings the sketches back). **To sketches** turns a model that is code into sketches you can go on with in Draw, in the same model. Paste and the code drop-down are gone: pasted or shared AI code and opened `.scad` files become a model.
- **Your code from 0.15 is kept:** code saved in Code or Paste becomes a model of its own (*My code*, *Pasted code*) in the model list.
- **Code's toolbar:** **Copy prompt**, **To sketches** and **Render** sit next to **Measure**. Edits go into the model when you tap Render (or Ctrl+Enter), go back to Draw, switch models or leave the app.
- **Colours in the code:** comments, keywords, shapes, transforms, functions, numbers, strings and `$` variables each have their own colour, in the light and the dark theme.
- **One line for problems:** under the code a single line says if there are problems in the code. **Full log** opens the list (with the lines and Fix buttons) and OpenSCAD's log, also when there are no problems (for `echo()`).
- **Top bar:** **Import**, **Export**, **Getting started** (+) and **Settings** are icons in the top right corner. The view buttons (Iso, Top, Front, Right, Fit) are one compact group.
- **Text on an underside:** text on a face that looks down (or to the back or the left) was mirrored seen from outside. It now reads the right way round, and its angle turns counterclockwise as seen from there. Text already on such a face turns round too.
