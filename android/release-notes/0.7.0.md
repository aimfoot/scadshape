Code from an AI chat now has its own way in, and the app catches and fixes more of the mistakes AI-written code makes.

- **From an AI chat, on the start card:** **Copy prompt** gives your AI the app's rules (which OpenSCAD and libraries it runs, your printer's build volume, angles in degrees, dimensions as variables at the top), and **Paste code** opens the answer as Custom code. A whole answer with text around the code is fine: only the code is kept. You can also share an answer from your AI app to scadshape.
- **Fix:** where the right change is clear, a problem gets a **Fix** button that shows the fixed line and makes the change. It covers `radians()` and `degrees()`, a missing BOSL2 or MCAD include, the old `assign()` and `child()`, `PI` in angles (`rotate([0, 0, PI/4])` → `rotate([0, 0, 45])`) and a leftover `%`, `*` or `!`. Guesses such as "did you mean width?" are left to you.
- **Silent mistakes are caught:** code that renders but comes out wrong, without a word from OpenSCAD: `sin(PI/2)` (OpenSCAD's angles are degrees), adding up in a loop, a part left out by `%`, `*` or `!`, a font the app doesn't have, a very high `$fn`, and an assembly of parts that would be merged into one body.
- **MCAD is included:** the library AI code often uses for gears, nuts and bolts now works, alongside BOSL2, Round-Anything, dotSCAD and gridfinity-rebuilt-openscad.
- **Common font names work:** Arial and Helvetica use Liberation Sans, Times uses Liberation Serif and Courier uses Liberation Mono, with the same letter widths. Liberation Serif and Liberation Mono are also new in the Text feature.
