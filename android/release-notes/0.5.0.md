OpenSCAD code you paste in – for example from an AI chat – now becomes a model you can change with its own variables.

- **Convert to sketches keeps the code's variables:** `width = 60;`, `wall = 2;` and `size = [40, 30, 2];` (as `size_x`, `size_y`, `size_z`) become variables in the model. Customizer sections are respected, so variables under `/* [Hidden] */` stay out unless a visible one uses them.
- **The dimensions follow the variables:** every dimension, extrude depth and sketch plane that depends on a variable gets the matching expression, such as `inner_x + 2 * wall` or `r - wall`. Change a variable under Variables and the model changes the same way it would if you edited the code.
- **Converted sketches are fully defined:** shapes keep the position the code gave them. Rounded rectangles drawn with `offset()` become editable rounded rectangles, and small polygons and revolve profiles get dimensions on their corners.
- Text and parts kept as code blocks (such as BOSL2 parts) don't follow the variables yet.
