Small improvements on top of 0.3.1.

- **See what you edit in portrait:** when a feature panel (Extrude, Hole, Text …) is open, the 3D view moves the model up above the panel instead of leaving it hidden underneath.
- **Dimension labels fit on narrow phones:** sketches keep room at the sides, so labels like `width = 30` are no longer cut off.
- **New font: Orbitron** in Regular, Bold and Black for the Text feature (and for OpenSCAD code that uses `font = "Orbitron:style=Black"`).
- **Clearer export text:** the exported 3MF/STL needs a slicer (Bambu Studio, OrcaSlicer, PrusaSlicer …). Phone printer apps such as Bambu Handy can't slice files themselves.
