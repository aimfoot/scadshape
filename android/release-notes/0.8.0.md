The app now checks the rendered model as well as the code, and the code is quicker to start over.

- **Parts in mid-air are found:** after every render, a part that starts above the bottom of the model with nothing under it gets a problem row marked **Model**, with where it is and how high it floats. It is also in **Copy for AI**. A typical AI mistake: a cut that takes away the top a neck or lid stands on, so the slicer would have to print it in thin air. Closed voids inside a body and parts standing on another part are not counted.
- **Clear:** a button in the corner of the code empties it, ready for the next answer from your AI chat. For a few seconds after, it turns into **Undo** in case it was a stray tap.
