Code from an AI chat now says what it is, and the model check finds overhangs and parts too big for your printer.

- **What the code says it is:** the comment at the top of the code shows above the model: its title, and a tap opens the parts and how they go together. The AI prompt asks for one (what it is, a line per part, and any design change a print rule forced), so you can see at a glance whether the AI made what you asked for.
- **Overhangs:** faces leaning out more than 45° from upright, reaching 2 mm or more, get a problem row under **Model**: they need support or droop. Screw threads are left alone – their 60° flanks print fine.
- **Too big for the printer:** a model larger than the printer chosen in Settings is now a problem row too, so **Copy for AI** tells the AI. Changing the printer updates the list at once.
- **Library hints with parameters:** when a BOSL2 or MCAD module fails a check, or gets an argument it doesn't have, the hint lists the module's parameters (for example, `threaded_nut()` needs `nutwidth`).
- **Better AI prompt:** clearances for parts that fit or move (0.4 mm for print-in-place joints, 0.2–0.3 mm for snap and slide fits), no overhangs over 45°, and all parts, gaps included, must fit on the bed.
- **Convert to sketches:** code blocks in a row are merged into one, so a honeycomb of holes is one block instead of hundreds.
- **Fewer false alarms:** a floor with drainage holes is no longer reported as a flat ceiling.
